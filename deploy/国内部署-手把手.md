# 天玑 · 售后看板 —— 国内环境部署·手把手

> 面向：国内网络环境、希望尽量省钱、需要给下属（客户成功经理）访问。
> 说明：完全"0 元 + 稳定 + 外网可访问"很难兼得，下面按推荐度给三条路，各自把「点哪里」写清楚。

---

## 先看清取舍（30 秒）

**路线一 · 国内云轻量服务器**：约 38～79 元 / 年，一台一直开机的机器，最稳定省心；用「IP + 端口」访问可**免备案**。适合当正式服务。**我最推荐这条。**

**路线二 · 内网穿透（cpolar 等免费版）**：真 0 元，服务还跑在你本机，只是借一条隧道让外面能访问；**免备案**。代价是免费版带宽小（1Mbps）、网址会随机变（不好长期给团队用），适合临时/演示。

**路线三 · 公司局域网**：真 0 元、最快、免备案、最安全；但只能在同一公司网络里访问。如果你们人都在一个办公室，这条其实最合适。

---

## 路线一：腾讯云 / 阿里云 轻量应用服务器（推荐）

### 第 1 步：注册与实名认证

打开浏览器进 **cloud.tencent.com**（腾讯云）或 **www.aliyun.com**（阿里云），点右上角「注册/登录」，用手机号注册。

注册后按提示做**实名认证**：个人用身份证、企业用营业执照。没实名认证买不了机器（这是国内规定，绕不开）。

### 第 2 步：买哪台、在哪买

腾讯云：顶部菜单「产品」→「计算」→「轻量应用服务器」，进去后找**「新用户专享 / 限时秒杀」**入口。当前行情大概是：4核4G3M、40GB 盘、300GB 月流量，**秒杀 38 元/年**，常规新人价 79 元/年。

阿里云：同样在「产品」→「轻量应用服务器」，新用户常有 2核2G 的 **38 元/年** 秒杀。

下单时三件事要选对：
- **地域**：选离你们公司最近的（华东选上海、华南选广州/深圳），访问最快。
- **镜像**：选操作系统 **Ubuntu 22.04**（别选宝塔/WordPress 那些应用镜像）。
- **时长**：按年买最划算。

> 小提示：秒杀款通常每天 10:00 和 15:00 两场，抢不到就直接买 79 元/年的也行，一年不到一顿饭钱。

### 第 3 步：买到后，先放行端口

回到「控制台」→「轻量应用服务器」→ 点进你那台实例 → 找「**防火墙**」（阿里云叫「安全组」）→「添加规则」：协议 **TCP**、端口 **8899**、来源 `0.0.0.0/0` → 确定。

这一步不做，外面就访问不到（最常见的坑）。

### 第 4 步：进服务器（点哪里）

在实例详情页，有一个「**登录**」按钮（有的叫「远程连接」），点它就打开一个**网页版的命令行黑窗口**，不用装任何软件。弹出的密码提示，先点实例页的「**重置密码**」设一个你记得住的 root 密码。

### 第 5 步：把代码传上去

在**网页终端**里粘贴下面这条（它会创建目录）：

```
mkdir -p ~/tianji-bi && cd ~/tianji-bi
```

然后回到你自己电脑（Mac），打开「终端」，粘贴下面这条（把 `你的公网IP` 换成实例页显示的公网 IP）：

```
cd "/Users/Apple/Desktop/外贸客户资料" && scp -r "客户续费BI看板" root@你的公网IP:~/tianji-bi
```

回车后会让你输刚才设的 root 密码，输完就开始上传（大约几十 MB，一两分钟）。

> 传完后，在**服务器的网页终端**里执行：`cd ~/tianji-bi/客户续费BI看板`

### 第 6 步：一键部署

在服务器网页终端里执行：

```
bash deploy/install-ubuntu.sh
```

它会自动装 Python、建运行用户、生成配置、装好开机自启服务、放行端口，最后打印一个访问地址。

### 第 7 步：填密钥，重启

编辑配置（在服务器网页终端里）：

```
nano .env
```

按提示把 **AI_API_KEY**、**FEISHU_APP_ID**、**FEISHU_APP_SECRET** 填上（Ctrl+O 保存、Ctrl+X 退出），然后：

```
sudo systemctl restart tianji-bi
```

### 第 8 步：打开看板

浏览器访问（把 IP 换成你的）：

```
http://你的公网IP:8899/tianji.html
```

能看到登录页就成功了。把你的天枢账号密码验证码登进去，页面就出来了。把这个网址发给下属即可。

### 关于「备案」和「HTTPS」（重要，别踩坑）

国内服务器用**域名**访问 80/443 端口**必须 ICP 备案**（要 1～2 周，个人可备）。为了省掉这一步，我们直接用 **http://IP:8899**，**不需要备案**。

代价是这个地址是 http（不是 https）。对内部工具来说够用；但请**别把它当公网站点对外宣传**，且一定保留看板自己的登录（天枢账号+短信验证码）这道门。

> 如果你坚持要 https 且不想备案：可以买**香港/新加坡**节点的轻量（免备案，能配域名+免费证书），但国内访问会慢一些。

## 路线二：内网穿透（真 0 元，服务留在你本机）

适合：临时给同事看、或你不想买服务器。

1. 打开 **www.cpolar.com**，注册账号（免费）。
2. 登录后进「验证」页，复制你的 **authtoken**。
3. 下载 **macOS** 客户端，解压到某个目录，打开「终端」进到该目录，执行：
   ```
   ./cpolar authtoken 你复制的authtoken
   ```
4. 确保你的看板服务已经在本机跑着（`python3 bi_server.py 8899`），然后执行：
   ```
   ./cpolar http 8899
   ```
5. 屏幕上会打印一个 `https://xxxx.cpolar.io` 的网址——这就是外网可访问的地址，发给同事即可。

**免费版的坑**（务必知道）：带宽约 1Mbps（够看表格，传大文件慢）；**随机网址大约每 24 小时会变**，所以不适合团队长期每天用。想固定网址要买它的小套餐。

**安全提醒**：穿透等于把你本机这个端口挂到公网了，务必确认看板登录开着，别把 `.env` 暴露出去。

## 路线三：公司局域网直连（真 0 元、最快、最安全）

如果同事都在同一个办公室：

1. 找一台**不关机的电脑**（旧台式机/小主机都行）当服务器。
2. 在它上面跑起服务：`python3 bi_server.py 8899`。
3. 在这台电脑上查它的内网 IP（Mac：系统设置→网络；Windows：`ipconfig`），形如 `192.168.1.50`。
4. 同事浏览器访问 `http://192.168.1.50:8899/tianji.html` 即可。

完全不出公网、无需备案、速度最快、最安全。缺点是只有在公司网络里能访问（人在外面连不上）。

---

## 无论走哪条，都请做这三件安全事

**一是密钥只放服务器**：AI 密钥、飞书凭证都写进服务器上的 `.env`（权限 600），永远不要出现在网页代码里（我们已确保前端零密钥）。

**二是保留登录这道门**：看板的登录用你的天枢账号 + 短信验证码，这是最有效的第一道防线，别为了省事把它去掉。

**三是不用时能一键停**：无法访问就把服务停了——`sudo systemctl stop tianji-bi`（云服务器），或直接关掉本机/穿透进程。

## 常见问题

**打不开网址？** 九成是云控制台的「防火墙/安全组」没放行 8899。回去补第 3 步。

**上传代码一直要密码？** 确认用的是 root 和你重置的密码；或改用在网页终端里 `git clone`（如果代码在仓库）。

**部署脚本报权限错？** 命令前加 `sudo`，或用 root 账号执行。

**想让每天数据自动更新？** 见同目录 `DATA-PIPELINE.md`，装好定时器即可（`sudo systemctl enable --now tianji-update.timer`）。
